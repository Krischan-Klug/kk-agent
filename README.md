# kk-agent-contract

Shared TypeScript contract package for KK-Agent.

Install from GitHub Packages:

```bash
npm install @krischan-klug/kk-agent-contract
```

The package is published to:

- `https://npm.pkg.github.com`

Required auth for local installs:

```bash
export NODE_AUTH_TOKEN=<github-packages-token>
```

Common commands:

```bash
npm install
npm run build
npm run lint
```
